## Nova Updated to 1.1.0

Nova was updated on October 8, 2026 to version 1.1.0. Nova and Nova.IO are both
1.1.0 and must be used together.

### Wrong results, now fixed

* mzML and mzXML files larger than 2 GB returned zero peaks for every scan,
  with no error. Re-check anything you produced from a large file.
* The mzML and mzXML readers reused one precursor object across every spectrum,
  so precursor details from one scan could appear on another. Each spectrum now
  has its own.

### Breaking

* Nova targets .NET Standard 2.0 instead of .NET Framework 4.8. One build now
  serves .NET Framework 4.8 and .NET 8 or later.
* `FramentationType` and `PrecursorIon.FramentationMethod` were misspelled.
  They are now `FragmentationType` and `FragmentationMethod`.
* Opening a file that cannot be read throws `SpectrumFileOpenException`.
  Earlier versions returned a reader that gave back empty spectra, so a bad
  path looked like an empty file.
* `ThermoRawReader` is no longer public. Use `FileReader` or
  `SpectrumFileReaderFactory.GetReader`, as with the other formats.
* `MzMLWriter.Write` returns nothing. It only ever returned true, and failures
  now throw.

### Pipes

The wire format changed to carry scan descriptions. A program running 1.1.0
cannot talk to one running 1.0.0.18, so upgrade both ends together.

### New

* MGF files can be read. The reader previously returned empty spectra.
* Scan descriptions are read from Thermo raw files and carried on the spectrum.
* `MzMLWriter.Write` can validate against the mzML schema. Off by default, and
  needs a local copy of the schema.
* Chromatogram counts are available from the readers and from `FileReader`.

### Also fixed

* Large messages over a pipe could be truncated.
* Deserializing a spectrum added precursors to those already present instead of
  replacing them.
* `PrecursorIon`'s copy constructor and `Clear` skipped collision energy,
  fragmentation method and isolation specificity.
* mzML recorded ion trap scans as "OTMS" instead of "ITMS".
* `FileReader` reported success after a failed open, and left `Format` as
  Unknown.
